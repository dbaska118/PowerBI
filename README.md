Repozytorium zawiera raporty przygotowane za pomocą programu PowerBI:
- IBM HR Analytics - analiza struktury zatrudnienia oraz identyfikacja czynników wpływających na rotację pracowników w firmie IBM.
- Global Superstore Analytics - analiza zbioru danych dotyczącego zamówień w globalnym sklepiepo pod kątem rentowności, logistyki dostaw, oferowanego asorytmentu oraz zachowań klientów.
